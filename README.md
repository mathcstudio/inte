# ∫ 정적분 탐구실 · 미적분Ⅰ — 설치·배포 안내

미적분Ⅰ(2022 개정) 범위에 맞춘 정적분 탐구 웹 앱입니다.
학생이 학번·이름으로 입장하면, **단계 달성 여부와 답변 내용**이 선생님의 **구글 스프레드시트**에 저장됩니다.

> 미적분Ⅱ(구분구적법·급수) 버전은 별도 저장소(`mathcstudio/integral`)에 그대로 있습니다.

## 탐구 구성 (15단계)

정적분을 **"잘게 나눈 직사각형 넓이의 합이 다가가는 값 = 방향과 부호를 가진 넓이"**로 도입하고,
**정적분 = 부정적분의 차(F(b) − F(a))**까지 다룹니다.

| 장 | 단계 | 내용 |
|---|---|---|
| ① 넓이를 구하는 아이디어 | 1~2 | 호수를 모눈으로 어림 → 잘게 나눌수록 정확한 이유 설명 |
| ② 곡선 아래 넓이와 정적분 | 3~4 | 직사각형 2개로 어림(5) → 한없이 잘게 나누면 약 2.67에 다가감 → 정적분 기호 (lim Σ는 '참고'로만) |
| ③ 방향과 부호를 가진 넓이 | 5~9 | 부호(높이 음수) · 위아래 섞임(S₁ − S₂) · **방향(b < a → 폭 Δx 음수, ← 화살표)** · 폭 0과 구간 나누기 · 정의 서술 |
| ④ 적분과 미분의 관계 | 10~12 | 넓이 함수 S(x) → m·Δx ≤ ΔS ≤ M·Δx → S′(x) = f(x) 설명 |
| ⑤ 부정적분과 정적분 | 13~15 | 적분상수 C가 빼면서 사라짐 → ∫₀² x² dx = 8/3 (4단계 어림값 확인) → **∫₋₁² (3x² − 8x) dx = −3 계산 후, 양수 부분 넓이 5에서 음수 부분 넓이 8을 뺀 값임을 서술** |
| 보너스 | — | 정적분 골프 (다항함수 97문제 중 9문제 무작위) |

'구분구적법', 급수 등의 용어는 쓰지 않고 학습지 표현("잘게 나눈 간단한 도형의 넓이의 합")을 따릅니다. AI 피드백도 같은 범위로 제한돼 있습니다.
## 구조

```
학생 브라우저 ──(GitHub Pages)── index.html            ← API 키·PIN 없음
     │
     └──▶ Google Apps Script (Code.gs) ──▶ Gemini API
              │  · 교사 PIN(해시), Gemini 키, 사용량 제한
              └─▶ 구글 스프레드시트: 진행현황 / 답변기록 / 골프기록
```

## 1단계. 스프레드시트 + 앱스크립트 서버 만들기

1. <https://sheets.google.com> 에서 **빈 스프레드시트**를 만들고 이름을 정합니다. (예: `정적분 탐구실 기록 2학년`)
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣고 저장합니다.
4. **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 꼭 이것을 선택 (학교 계정이라 이 항목이 없으면 개인 Gmail로 만드세요)
5. 권한 승인 후 표시되는 **웹 앱 URL**(`…/exec`)을 복사합니다.

> 스프레드시트 안에서 만든 스크립트라서 기록이 바로 그 시트에 쌓입니다. 탭(진행현황·답변기록·골프기록)은 첫 기록 때 자동으로 생깁니다.

## 2단계. 앱에 서버 주소 넣기

[`index.html`](index.html)에서 아래 줄에 복사한 주소를 넣습니다.

```js
const GAS_URL = 'https://script.google.com/macros/s/…/exec';
```

## 3단계. GitHub Pages 배포

1. GitHub에서 새 **Public** 저장소를 만들고 이 폴더의 파일을 올립니다.
2. **Settings → Pages** → Branch: `main` / `(root)` → Save
3. `https://<아이디>.github.io/<저장소이름>/` 주소를 학생에게 안내합니다.

## 4단계. 첫 관리자 설정 (꼭!)

1. 사이트 입장 화면에서 **🔐 선생님(관리자)으로 들어가기** → PIN `1234`
2. Gemini API 키, **새 PIN** 입력 → 저장 → **연결 테스트**
3. **📊 학생 기록 시트 열기** 링크로 시트가 연결됐는지 확인
4. **👀 선생님 체험으로 들어가기**로 학생 화면을 미리 볼 수 있습니다. (체험 기록은 저장되지 않음)

## 스프레드시트에 쌓이는 내용

| 탭 | 내용 |
|---|---|
| **진행현황** | 학번, 이름, 처음 접속, 마지막 활동, 완료 단계 수, 1~15단계별 완료 시각(✅) |
| **답변기록** | 시각, 학번, 이름, 단계, 문항 유형, **학생 답**, 결과(정답/오답/통과/미통과/풀이 열람), 피드백, 시도 횟수, 힌트 사용 수 |
| **골프기록** | 시각, 학번, 이름, 코스 번호, 총 타수, 기준 타수, 홀별 타수 |

- 15단계처럼 문항이 두 개인 단계는 '15. … ①', '15. … ②'로 따로 기록됩니다.
- 같은 학번으로 다른 기기에서 들어오면 진행 상황이 이어집니다.
- 인터넷이 잠깐 끊겨도 기록은 기기에 모아 두었다가 다시 연결되면 보냅니다.

## 방탈출 모드 〈정적분 연구소 탈출〉

관리자 화면에서 **🔐 방탈출 모드**를 켜면, 같은 15단계를 방 5개로 꾸며 보여 줍니다. 문항·채점·기록은 그대로입니다.

| 방 | 단계 | 열쇠 조각 |
|---|---|---|
| 🗺 지도실 | 1~2 | 📓 연구 일지 |
| 📐 측량실 | 3~4 | 🧩 금고 번호 조각(≈2.67) |
| 🪞 거울의 방 | 5~9 | 🔢 다이얼 번호(−2·0·−4·6) |
| ⚙ 기계실 | 10~12 | 🔧 기계 가동 열쇠 |
| 🔐 마지막 금고 | 13~15 | 🗝 출구 열쇠 → 탈출 증명서 |

- 방에 처음 들어가면 이야기 카드, 단계마다 단서 문장(🔦), 힌트는 '📜 연구원의 쪽지'로 바뀝니다.
- 틀리면 자물쇠가 흔들리고, 맞히면 🔓가 열립니다.
- 탈출 시간은 **기록만** 하고 제한하지 않습니다. 탈출하면 답변기록에 `탈출` 결과(걸린 시간, 쪽지 수)가 남고, 반별 현황에 **🔐 연구소 탈출 인원**이 표시됩니다.
- 관리자 설정과 상관없이 주소 끝에 `?mode=escape`를 붙이면 그 화면만 방탈출 모드로 열립니다. (미리 보기용)
## 관리자: 반별 학습 현황

관리자 화면 → **📊 반별 학습 현황 보기**

- **반 구분:** 학번의 둘째·셋째 자리 (예: 20812 → 8반). 5자리가 아닌 학번은 '기타'.
- **전체 탭:** 반별 학생 수, 평균 완료 단계, 전체 달성률, 단계별 달성률(%) 비교표
- **반 탭:** 단계별 달성률 막대, 학생별 진행표, 학생 답변(단계별 필터, 학생별 마지막 답만 보기, 학생을 누르면 그 학생 답변만)
- 데이터는 스프레드시트에서 불러오며, **↻ 새로고침**으로 최신 기록을 다시 가져옵니다. (답변은 최근 4000건)

## 알아두실 점

- **본인 확인은 하지 않습니다.** 학생이 입력한 학번·이름을 그대로 기록하므로, 수업 중 안내가 필요합니다.
- 학생 개인정보(학번·이름·답변)를 수집하므로, 학교의 개인정보 처리 지침에 맞는지 확인하고 학생에게 미리 안내해 주세요.
- 기록 시트는 선생님 구글 드라이브에만 있고, 공유 설정을 바꾸지 않는 한 다른 사람은 볼 수 없습니다.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 버전: 새 버전 → 배포** (주소 유지)

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 기록이 시트에 안 쌓임 | `GAS_URL` 주소, 배포 액세스가 '모든 사용자'인지 |
| 배지가 "AI 피드백 꺼짐" | 관리자 화면에서 키 저장·AI 켜기 여부 |
| "학번 형식이 올바르지 않아요" | 학번은 숫자·영문 2~12자 |
